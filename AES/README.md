This project implements the AES encryption algorithm in C language, supporting three key lengths: AES-128, AES-192, and AES-256. Users can flexibly adjust the algorithm type and the size of the input data block by setting parameters. By default, the project is configured to use AES-128 based on the iterable gadget implementation described in this work, with an input data block size of 64.

File Structure Description：

**RPE Gadgets Directory**：

This directory provides implementations of addition/copy/multiplication gadgets generated using the method described in Ref. [16]. These gadgets support masking orders 2, 3, 4, 8, 9, 16, and 27, and can be substituted into specific locations within the AES algorithm. It contains:

- **2-share Subdirectory:** Contains function code for higher-order masked gadgets generated by extending the 2-share gadget basis.
- **3-share Subdirectory:** Contains function code for higher-order masked gadgets generated by extending the 3-share gadget basis.

**AES-128-192-256 Directory**：

- **main.c:** Main program file containing the AES encryption and decryption processes.
- **AES_DATA_{size}:** (e.g., `AES_DATA_16384`) Data files for testing with different block sizes.
- **Makefile:** Build file used to compile the project.
- **aes_files Subdirectory:**
  - aes128_sharing.h, aes128_sharing.c：contains the protected implementation of the n-share AES algorithm.
  - gadgets.h, gadgets.c: contains the three n-share gadgets functions (add, copy, mult), as well as the n-share variables generation and compression functions.
  - gf256.h, gf256.c: contains the functions for addition and multiplication in the field GF(256).

**Experiment 1: Testing Different Masking Orders (n-share)**

This experiment aims to evaluate the impact of different masking orders on the AES algorithm.

**Our Scheme (Based on Iterable Gadgets):**

This scheme allows adjusting the masking order by modifying a single macro definition.

1. Open the `gadgets.h` file.  Locate the macro definition: `#define NB_SHARES 27`. Change the value `27` to the desired masking order `n` (`n` must be an integer greater than 1).
   - **For example:** To set a 5-share mask, change it to `#define NB_SHARES 5`
2. After modification, recompile the project and run it to obtain AES computation results using the `n`-share mask.

**Control Group Scheme (Based on RPE Gadgets):**

This scheme requires replacing the core gadget functions with specific higher-order masked gadget implementations provided in the RPE Gadgets directory.

1. Modify the Masking Order:  Locate the macro definition: `#define NB_SHARES 27`. Change the value `27` to the target masking order `n`

2. Replace the Core Gadget Functions: Open the `gadgets.c` file. Locate and replace the implementation code for the following three functions:

   void add_gadget_function(uint8_t * a, uint8_t * b, uint8_t * c);

   void copy_gadget_function(uint8_t * a, uint8_t * d, uint8_t * e);

   void mult_gadget_function(uint8_t * a, uint8_t * b, uint8_t * c).

   Replacement Method:

   - Based on the target masking order `n` and the chosen gadget basis (e.g., `3-share`), navigate to the corresponding subdirectory within the `RPE gadgets` directory (e.g., `RPE gadgets/3-share`).
   - Locate the gadget implementation files corresponding to order `n` (e.g., `27-share_add.c`, `27-share_copy.c`, `27-share_mul.c`).
   - Completely copy the relevant function code from these files.

3. Compile and Run: After completing the code replacements, recompile the project and run it. This will yield AES computation results using the `n`-share mask implemented via the RPE gadgets

   

**Experiment 2: Configuring AES Key Length and Input Data Block Size**

This experiment details how to configure the project to use different AES key lengths (AES-128, AES-192, AES-256) and different input sizes.

**Configuration Steps (Using AES-128 as an example):**

1. Modify the `aes128.h` file:

   - Locate the macro definition `#define AES_ROUNDS`, set its value to `10`.

   - Locate the macro definition `#define AES_ROUND_KEY_SIZE`, set its value to `176`.

2. Modify the `aes128.c` file:

   - Within the function `aes_decrypt_128`, locate the statement `roundkeys += 160`, ensure it is set to `160`.

3. Modify the aes128-sharing.c file:

   - Within the function `aes_decrypt_128_sharing`, locate the statement initializing `ind_roundkeys`

   - Ensure its initial value is set to `ind_roundkeys = 160;`

4. Modify the `aes128_sharing.c` file:

   - Locate the key schedule function call, change `aes_key_schedule_xxx(key, roundkeys)` to `aes_key_schedule_128(key, roundkeys)`.

5. Modify the input data file (in `main.c`)

   - Locate the code line reading the input data, modify the filename parameter, replace `AES_DATA-64` with the desired data block filename (for example `AES_DATA-2048`, `AES_DATA-16384`).

After completing the configuration, please recompile the project and run it.


Configuring AES-192 and AES-256 follows the same steps as AES-128, with parameter values provided in subsequent comments.
